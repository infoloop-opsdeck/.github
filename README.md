# infoloop-opsdeck / .github

Org-wide defaults for every repository in `infoloop-opsdeck`:

- `pull_request_template.md` – default PR description
- `ISSUE_TEMPLATE/` – bug, feature and Enterprise request forms
- `CONTRIBUTING.md` – branching, commits, reviews, releases
- `SECURITY.md` – how to report a vulnerability

Note: GitHub applies issue/PR template defaults across the org only when this
repository is **public**. It contains nothing confidential by design. Keep it that way.

Engineering standards and architecture live in
[`opsdeck-handbook`](https://github.com/infoloop-opsdeck/opsdeck-handbook).
